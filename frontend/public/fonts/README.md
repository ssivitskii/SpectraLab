# Golos Text

Self-hosted variable font, weights 400–700, used by the Photon interface.

- [Upstream font and licence](https://github.com/google/fonts/tree/main/ofl/golostext)
- [Google Fonts delivery stylesheet](https://fonts.googleapis.com/css2?family=Golos+Text:wght@400..700&display=swap)
- Licence: SIL Open Font License 1.1; full text in `OFL-Golos-Text.txt`.

The four WOFF2 files cover Latin, extended Latin, Cyrillic and extended Cyrillic.
The app serves them locally and does not contact Google Fonts at runtime.
