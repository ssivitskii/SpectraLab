## Критерии готовности изменений

Задача закрывается после реализации, целевой проверки её критерия и обновления
документации. Для изменений кода сохраняется текущий набор команд CI:

```bash
make api-types
git diff --exit-code -- frontend/src/api/schema.d.ts
make lint test build demo analytics
make browser-install
make e2e
```

Проверка diff сгенерированных типов выполняется после включения обновлённой схемы
в коммит: повторная генерация не должна менять её. E2E включён в CI; серии воспроизводятся через `make series CONFIG=...`.
Большие исследования запускаются отдельно от smoke и обычного CI.

Во всех направлениях сохраняются ограничения: `component_weights` не являются
концентрациями; некалиброванный score не называется вероятностью; синтетическое
качество не переносится на реальные измерения без проверки; true labels не
поступают в predictor; test не используется для настройки. Большие данные, модели
и локальные результаты остаются вне Git.
