# ML08: внешняя валидация ChemCam

**Завершена 2026-10-13** на другом наборе: NASA PDS ChemCam preflight laboratory
calibration. Подтверждены лицензия, вакуумная шкала, прибор и эталонный состав;
выполнен зафиксированный synthetic→real тест на **64 физических образцах,
255 спектрах, трёх baseline и пяти seed**. Низкие результаты обнаружения —
результат проверки, а не основание менять test или объявлять модель готовой к прибору.

## Источник и допуск

- Данные: [официальный каталог PDS CALIB](https://pds-geosciences.wustl.edu/msl/msl-m-chemcam-libs-4_5-rdr-v1/mslccm_1xxx/calib/),
  DATA_SET_ID `MSL-M-CHEMCAM-LIBS-4/5-RDR-V1.0`, DOI `10.17189/1519485`.
- Лицензия: карточка [NASA Open Data](https://data.nasa.gov/dataset/msl-mars-chemcam-libs-spectra-4-5-rdr-v1-0-f9501)
  явно указывает **us-pd**, public-domain label 1.0. Идентификатор совпадает с PDS label
  скачанного продукта; право использования не выведено только из публичности архива.
- Шкала: **vacuum, nm**. [Wiens et al., 2013](https://doi.org/10.1016/j.sab.2013.02.003),
  обсуждение калибровки по Ti, прямо сообщает: “we calibrated to vacuum wavelengths”.
  Доступна [авторская копия](https://www.researchgate.net/publication/257236897_Pre-flight_calibration_and_initial_data_processing_for_the_ChemCam_laser-induced_breakdown_spectroscopy_instrument_on_the_Mars_Science_Laboratory_rover).
  Вывод основан на описании калибровки, а не на атмосфере измерения.
- `calinfo.txt` связывает preflight-файл с cleanroom Test 6 и этой публикацией.
  Прибор — лётный ChemCam; лабораторная съёмка при примерно 7 Torr CO₂, комнатной
  температуре и расстоянии 3 m. Сводный продукт не даёт индивидуальных дат:
  вся кампания консервативно считается **одной сессией**, целиком внешней.
- Состав: официальный `ccam_calibration_compositions.csv`, точное сопоставление
  `Spectrum Name`. Это эталонные лабораторные стандарты, описанные в разделе 2.2
  и Table 3 Wiens et al., не предсказанные составы марсианских пород. PDS-описания
  полей местами повторяют слово `Predicted`; основание интерпретации сохранено
  отдельно. FeOT отличается от табличного Fe₂O₃ пересчётом общего железа;
  здесь используется лишь подтверждённое положительное присутствие.

[Реестр происхождения](../data/reference/chemcam_external_source.json) содержит
URL, SHA-256 четырёх входных файлов, документальные основания и checksum снимка
карточки лицензии. Исходные CSV остаются в `data/raw/chemcam_external/` вне Git.

## Зафиксированный эксперимент

[Протокол](../data/reference/chemcam_external_protocol.json) сохранён до первого
обучения/предсказания в этой проверке. Из 66 имён исходной матрицы взяты все 64 с
единственным точным соответствием в таблице состава; `M6-HAGGERTY` и `SGR1`
исключены из-за отсутствующего или неоднозначного соответствия, без отбора по сигналу
или качеству модели. 255 исходных колонок анализируются отдельно; усреднённые CSV
используются только для технического допуска и не подменяют повторы при prediction.

У Na 63 положительных физических образца, у Mg/Ca/Fe — по 64. Всего **255
положительных пар «образец–элемент»**; это отдельная величина, случайно совпавшая
с числом спектров. Положительная конечная массовая доля Na₂O/MgO/CaO/FeOT даёт
положительную метку. Ноль, пропуск и отрицательное значение считаются неизвестными;
**H и He не размечены**. Нет подтверждённых отрицательных меток, поэтому precision,
F1, specificity и false-positive rate в отчёте имеют значение `null`.

Сетка модели 350–800 nm с шагом 0.1 nm; используются только окна **383–468 и
500–800 nm**, заданные до предсказаний по покрытию прибора. Разрыв больше 0.5 nm
внутри наблюдаемого окна отклоняется. Отсутствующие диапазоны удаляются из признаков
и шаблонов; структурные нули в сохранённом полном массиве не считаются измерениями.
Нормировка max-abs вычисляется только по наблюдаемым признакам.

Обучение и подбор порогов используют только синтетику из проверенного NIST cache:
240 независимых составов, по два шумовых повтора, разделение 144/48/48 по base ID,
смеси 1–3 элементов, Gaussian FWHM 0.5 nm, SNR 20–40 dB. Веса 0.35–1.2 — вклады
шаблонов, не концентрации. Для seed **7, 17, 29, 43, 71** NNLS, Logistic OVR и RF
получают одинаковые данные. Артефакт модели и пороги сохраняются до её внешнего
prediction. Нет real-data alignment, дообучения, калибровки или выбора лучшего seed.

Для каждой пары «физический образец–элемент» сначала усредняется бинарное обнаружение
по её повторным спектрам. Сначала считается recall каждого образца по известным
положительным элементам, затем равное среднее по образцам. Повторы и различное число
известных меток одного образца не увеличивают его вес. Доверительные интервалы получены bootstrap
по физическим образцам (1 000 повторов, seed 20261013), условно на одной кампании.
Они сохранены отдельно для каждого seed; SD между seed описывает другой источник
вариации и не выдаётся за доверительный интервал или межприборную воспроизводимость.

## Измеренные результаты

Среднее recall ± SD между пятью seed; шкала 0–1.

| Модель | Равное среднее по образцам | Na | Mg | Ca | Fe |
| --- | ---: | ---: | ---: | ---: | ---: |
| NNLS | 0.0374 ± 0.0000 | 0.0833 ± 0.0000 | 0.0156 ± 0.0000 | 0.0000 ± 0.0000 | 0.0469 ± 0.0000 |
| Logistic OVR | 0.4549 ± 0.0812 | 0.5897 ± 0.3364 | 0.0531 ± 0.0479 | 0.1844 ± 0.3351 | 0.9914 ± 0.0080 |
| Random Forest | 0.6827 ± 0.0882 | 0.8976 ± 0.1384 | 0.3859 ± 0.3335 | 0.5773 ± 0.3574 | 0.8750 ± 0.1634 |

На синтетическом test NNLS и Logistic OVR получили F1 = 1.0; RF — 0.9499–0.9846.
Расхождение с внешним recall показывает пределы переноса этого конкретного
синтетического протокола. Высокий recall сам по себе не доказывает полезности:
модель, называющая все элементы, тоже получила бы recall = 1.0. Нельзя выбирать
победителя для эксплуатации без независимой оценки ложных срабатываний.

Нейтральные Gaussian-шаблоны не моделируют ионную/молекулярную плазму, матричные
эффекты и элементы вне текущих шести классов. Химическое присутствие не гарантирует
видимую линию в выбранном диапазоне. Это **завершённая ограниченная внешняя проверка
обнаружения**, не оценка концентраций и не подтверждение качества на другом приборе.
Исследовательские модели с маской не заменяют автоматически модели общего API.

## Воспроизведение и артефакты

```bash
# Первый запуск: скачать четыре фиксированных файла с проверкой TLS и SHA-256
make external-validation-download
# Последующие запуски без сети
make external-validation
```

Каждый запуск создаёт новый каталог. Исходный завершённый run:
`reports/external/chemcam-external-20261013T152342-d190b46e/`.
В нём protocol/source и их hashes, hashes исходников, admission, original-column IDs,
external features, synthetic splits/records, 15 моделей, пороги, все предсказания,
per-element support/пропуски/неизвестные метки и интервалы.
Компактный [сохранённый отчёт](external_validation_summary.json) версионируется.
Тесты проверяют пропуски шкалы, нормировку по маске, round-trip, разделение групп,
отказ при real development и независимость интервала от дублирования повторов.
