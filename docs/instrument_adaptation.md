# Адаптация ChemCam и проверка ложных срабатываний

Исследовательский профиль решает согласованную задачу превышения уровня содержания
для Na, Mg, Ca и Fe. Метки взяты из независимых опубликованных анализов стандартов:
Na2O, MgO, CaO и FeOT, в массовых процентах оксида. Это не оценка концентрации по
спектру и не доказательство полного отсутствия элемента.

| Опубликованное содержание | Метка для проверки |
| --- | --- |
| `0 < x ≤ 0.1 wt%` | Отрицательная |
| `x ≥ 1.0 wt%` | Положительная |
| Ноль, пропуск, отрицательное значение или `0.1 < x < 1.0` | Неопределённая |

Номинальный уровень решения — 0.5 wt% с защитным промежутком. Нули не превращаются
в подтверждённое отсутствие: публикация отдельно предупреждает о неполных анализах.
У таблицы нет неопределённости каждого значения, поэтому метки являются операционными
по опубликованным оценкам. H и He этим исследованием не проверяются.

## Источники и независимость

Использованы лабораторные `calib_2015` и `calib_2021` из
[NASA PDS ChemCam](https://pds-geosciences.wustl.edu/msl/msl-m-chemcam-libs-4_5-rdr-v1/mslccm_1xxx/calib/).
[Карточка NASA](https://data.nasa.gov/dataset/msl-mars-chemcam-libs-spectra-4-5-rdr-v1-0-f9501)
явно указывает `us-pd`; идентификатор набора проверяется в PDS label каждого файла.

Шкала — **vacuum, nm**. Основание: метод калибровки Ti по вакуумным линиям в
[Clegg et al. 2017](https://doi.org/10.1016/j.sab.2016.12.003), на который ссылается
раздел лабораторной калибровки
[Gasda et al. 2021](https://doi.org/10.1016/j.sab.2021.106223).
CALINFO связывает эти методы с двумя папками архива. Давление в камере само по себе
не используется как свидетельство шкалы длин волн.

Отбор выполнен по метаданным и составам до обучения и расчёта предсказаний:

- Development: первый пространственный отсчёт стандартов 2015, все доступные
  низкие содержания плюс детерминированная выборка остальных до 128 файлов.
- Итоговая проверка: все подходящие новые стандарты 2021 с первым файлом не ранее
  2016 года. Исключены псевдонимы любых стандартов 2015, ранее проверенные preflight
  материалы и известные производные смеси. Фактические даты — 2017–2019 годы.
- Отсутствующий в архиве первый файл JSC1413 исключён отдельной поправкой источника
  до обучения. Другой пространственный отсчёт вместо него не выбирается.
- Повторные опубликованные Sample Name объединяются в один физический материал;
  MIX-серия, SanC и WMB24a/b группируются консервативно. Сессии определены датой
  измерения. Связанные физические материалы, семейства, сессии и одинаковые файлы
  не пересекают границы выборок.

Входной реестр, исключения и доказательства:
`data/reference/chemcam_adaptation_intake.json`,
`chemcam_adaptation_alias_audit.json`, `chemcam_adaptation_source_amendments.json`.
Окончательный протокол с SHA-256 находится в
`data/reference/chemcam_adaptation_protocol.json`.

## Модель и выбор порогов

Один файл даёт одно усреднение импульсов 6…N. Первые пять импульсов исключаются;
столбцы среднего/медианы поставщика не используются. Читатель проверяет SHA-256,
заголовок, число импульсов, конечность и возрастание оси. Наблюдаемые окна
383–468 и 500–800 nm интерполируются на сетку 0.1 nm без соединения разрывов
более 0.5 nm. Промежуток между спектрометрами не является наблюдаемым сигналом.

Для адаптации берётся максимум в фиксированных интервалах 1 nm, отрицательная
интенсивность обрезается до нуля, каждое окно нормируется по сумме и применяется
`log1p(1000*x)`. StandardScaler и четыре логистические модели обучаются только на
train; неизвестные метки исключаются. Повторы одного физического материала имеют
суммарный вес один. Профиль хранит числовое состояние JSON/NPZ без pickle.

Train/tune разделяются по связанным группам, детерминированно, с двумя независимыми
положительными и отрицательными группами каждого класса в каждой части. Для
`C ∈ {0.01, 0.1, 1}` пороги выбираются только на tune: максимальный recall при
наблюдаемом FPR ≤ 5%; при равенстве — меньший FPR и больший порог. Выигрывает
наибольшая средняя balanced accuracy, затем меньшее C. На tune модель не дообучается.
Пять процентов — критерий настройки, **не гарантированный FPR на новых данных**.

Сравнение проводится с NNLS на закреплённом нейтральном справочнике NIST.
Его пороги выбираются по тем же tune-образцам и тому же правилу. Поэтому сравнение
проверяет вклад приборных признаков и обучения, учитывая настройку порогов обеих моделей.
Score логистической модели и NNLS не объявляется вероятностью.

Модель, пороги и справочник сохраняются до чтения итоговых спектров. Реестр
использования test создаётся атомарно и синхронизируется с диском; он остаётся
после сбоя. Повтор требует `--replay` и полного совпадения протокола, модели,
baseline и реализации. Это воспроизведение, а не новая независимая проверка.

## Метрики

Recall, FPR и precision по известным меткам считают с равным весом физических
материалов. Неопределённые метки исключены из знаменателей; их предсказания
сохранены отдельно. Precision зависит от состава выбранного набора и не переносится
на произвольную частоту встречаемости материалов.

Для разностей моделей используются одинаковые 2 000 bootstrap-перевыборок
связанных групп физических материалов/семейств/сессий/checksum. Интервалы условны
на фиксированных моделях, не учитывают ошибку химического анализа и не являются
одновременными для всех элементов. При недостаточной поддержке или вырожденном
bootstrap интервал оставляется `null` с причиной; ноль ошибок не означает нулевой
популяционный риск.

Нулевой FPR Na/Mg/Ca означает только отсутствие ошибок на 30/21/10 известных
низкосодержащих материалах. В частности, Mg не обнаружен ни на одном из 19
положительных материалов, поэтому ноль ложных срабатываний здесь не является
успехом. Precision 100% Na/Ca относится только к предсказаниям на известных метках,
а не ко всем возможным образцам.

Парные 95% кластерные интервалы разности recall (адаптация минус NNLS):
Na −46.4 п.п. [−81.0; −8.0], Mg −63.2 [−86.7; −46.2], Ca +35.0 [−18.6; +78.4],
Fe +42.5 [−16.3; +90.6]. Для Fe разность FPR +41.2 п.п. [+5.9; +66.7].
Таким образом, рост recall Ca/Fe не даёт надёжного основания объявить модель
лучшей в целом; ухудшение Na/Mg и высокий FPR Fe ограничивают применение.

## Воспроизведение и применение

```bash
make instrument-data
make instrument-freeze
make instrument-adaptation

# Повтор уже использованного test: только тот же протокол и та же реализация.
.venv/bin/python scripts/adapt_chemcam.py --replay

# Применение сохранённого профиля к новому файлу того же прибора.
.venv/bin/python scripts/predict_instrument.py \
  --artifact reports/adaptation/<run-id>/profile \
  --input /absolute/path/new_ccs.csv \
  --instrument-id chemcam-lanl-testbed \
  --output reports/new-instrument-prediction.json
```

Большие исходные данные, модели и подробные отчёты остаются локально, вне Git.
Сохраняются точные URL, SHA-256, параметры и компактный отчёт. Обычный API распознавания
элементов не подменяется этим приборным профилем с другой трактовкой меток.

Профиль проверяется на лабораторном LANL ChemCam testbed, не на другом приборе
или марсианских измерениях. Нет отдельного blank-эксперимента, проверки предела
обнаружения или атрибуции улучшения отдельным физическим механизмам. Для дальнейшей
настройки после этого результата понадобится новая закрытая итоговая выборка.
