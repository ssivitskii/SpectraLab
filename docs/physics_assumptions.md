# Физические допущения

Demo использует `demo_fixture`, нейтральные H, He, Na, Mg, Ca, Fe, vacuum nm,
350–800 nm и сетку 0.05 nm. Сохранённый источник NIST для шести элементов
выбирается явно: `data/reference/nist_neutral_350_800/catalog.json`.
Он содержит исходные выгрузки, URL, версию, raw SHA-256 и checksum нормализованного
каталога. Совпадающая округлённая длина волны не означает дубликат перехода.

## Генератор

Сигнал — сумма линий с положительными `component_weights`. Интенсивность из
справочника используется как prior (при отсутствии — 1). Она не задаёт абсолютную
мощность и не имеет общей шкалы между элементами. Log-normal вариация амплитуды
воспроизводима по seed. Веса вкладов не являются концентрациями.

| Параметр | Значение и единицы |
| --- | --- |
| `profile` | `gaussian` или `voigt`, интеграл по каждому пикселю |
| `instrumental_fwhm_nm` | Gaussian FWHM, nm; σ = FWHM / (2√(2 ln 2)) |
| `lorentzian_fwhm_nm` | Lorentz FWHM, nm; γ = FWHM / 2; только Voigt |
| `noise_model` | `gaussian` или `poisson_read` |
| `snr_db` | Заданный Gaussian SNR в dB; для Poisson обязательно null |
| `photon_scale` | Ожидаемые фотоотсчёты на условную единицу сигнала |
| `read_noise_std` | Стандартное отклонение независимого шума считывания, условные единицы |
| `response_slope` | Безразмерное изменение отклика от центра к краю; отклик в центре 1 |
| `saturation_level` | Верхний предел сигнала в условных единицах после шума; null отключает |
| `ion_stage` | 1 — нейтральный атом; 2 — однократно ионизованный и т. д. |

Gaussian интегрируется разностью CDF. Voigt интегрируется квадратурой с адаптивной
проверкой узкого ядра. Профиль имеет единичную площадь на бесконечной оси; потерянные
за конечным окном хвосты **не перенормируются**. При Lorentz FWHM=0 результат
побитово совпадает с Gaussian. Тесты проверяют массу конечного окна и субпиксельный пик.

Порядок обработки: профиль → отклик детектора → фон → Poisson или Gaussian noise →
read noise → насыщение. `clean_signal` содержит профиль после отклика и ограничения
насыщения, без фона и шума. Для Gaussian шум задаётся через
σ_noise = √mean(clean²) / 10^(SNR_dB/20), до насыщения.
Poisson требует неотрицательного ожидаемого сигнала и использует
Poisson(signal × photon_scale) / photon_scale. Отрицательный read/Gaussian noise
сохраняется. `snr_db: null` не означает отсутствие Poisson/read noise.
Единицы также сохраняются в `generator_parameters.units` model manifest.

## Ионы и длины волн

Линия идентифицируется парой `(element, ion_stage)`. Генератор и registry используют
явную стадию проекта; `models/ions.py` строит раздельные шаблоны нескольких стадий.
Агрегация решений к элементу — логическое OR уже пороговых boolean detections.
Суммирование score разных ионов не превращает их в вероятность элемента.

`data/wavelengths.py` выполняет отдельное преобразование стандартного воздуха:
Peck & Reeder, JOSA 62, 958 (1972), DOI: 10.1364/JOSA.62.000958.
Используется [конвенция NIST ASD](https://physics.nist.gov/PhysRefData/ASD/Html/lineshelp.html#REFRACTIVE):
15 °C, 101325 Pa, CO₂ 0.033%, диапазон 185–1690 vacuum nm.
Для s=1000/λ_vac[nm]:

`n = 1 + 1e-8 × (8060.51 + 2480990/(132.274−s²) + 17455.7/(39.32957−s²))`.

λ_air = λ_vac/n; обратное преобразование итеративное. Проверяется опубликованный
эталон 200.0648 vacuum nm ≈ 200.0000 air nm и round-trip. Источник, исходная среда
и условия остаются в provenance преобразованного каталога. Обычный CSV/API импорт
не угадывает среду и отклоняет air до явного преобразования. Старые модели без
`schema_version: 2` требуют переобучения, а несовместимые ion stages отклоняются.

## Границы применимости

Voigt и детекторные механизмы — управляемые приближения, не полная модель прибора.
Не моделируются LTE/non-LTE популяции, self-absorption, физический continuum,
измеренная QE-кривая и плазменная динамика. Справочные относительные интенсивности
NIST зависят от источника возбуждения. Синтетическое качество не переносится на
реальные измерения без внешнего теста. Диагностические линии не объясняют решение
модели причинно. Отдельное исследование отказа от ответа описано в протоколе.
