# LTE-генератор плазмы и устойчивая предобработка · 2026-10-22

Прежняя проверка synthetic→real на ChemCam ([ML08](external_validation.md)) показала,
что линейная смесь нейтральных шаблонов NIST почти не переносится на реальный
лазерно-индуцированный спектр: NNLS нашёл 3,7% известных положительных меток.
Эта итерация меняет две вещи: физику генератора и представление спектра для моделей.
Ниже описано, что реализовано, как это проверено и что из этого следует.

**Статус проверки: replay.** 64 стандарта preflight-кампании уже раскрыты прогоном v1.
Новый прогон — development-свидетельство о генераторе, а **не независимая финальная
оценка** и не квалификация модели. Протокол
[`chemcam_plasma_replay_protocol.json`](../data/reference/chemcam_plasma_replay_protocol.json)
зарегистрирован до запуска; отчитываются все варианты и seed, ничего не выбирается по
реальным результатам.

## 1. Физика генератора

Модуль [`simulation/plasma.py`](../ml/src/spectralab_ml/simulation/plasma.py).
Для каждой однородной зоны плазмы с температурой T и электронной плотностью n_e:

| Механизм | Реализация |
| --- | --- |
| Ионизация I/II | уравнение Саха с понижением потенциала ионизации по Дебаю, Δχ ≈ 2.9·10⁻⁸ z (n_e/T)^½ эВ |
| Заселённости | закон Больцмана; статсуммы по уровням NIST ниже χ − Δχ (иначе ридберговская серия расходится) |
| Линии | все переходы NIST с A_ki, E_i, E_k, g_i, g_k; стадии I и II одновременно |
| Профиль | псевдо-Фойгт: штарковская лоренцева ширина ∝ n_e (у H — ∝ n_e^⅔), доплеровская по массе и T |
| Перенос излучения | однородный слой: I = B_λ(T)·(1 − e^{−τ(λ)}); даёт самопоглощение и сложение перекрывающихся линий, в тонком пределе совпадает с излучательной способностью |
| Континуум | тормозное и рекомбинационное излучение по Крамерсу–Унзольду, ∝ n_e n_ion T^{−½} λ^{−2} |
| Интегрирование по времени | сумма горячей (9000–14000 K) и холодной (5500–9000 K) зон со случайным весом |
| Прибор | гауссова аппаратная функция для каждого спектрометра, сдвиг и растяжение шкалы, гладкий отклик и фон, дробовой шум и шум считывания |
| Состав | целевые элементы присутствуют с вероятностью 0.55, массовая доля лог-равномерна; матрица O, Si, Al, K, Ti, Mn и атмосферный C добавляются независимо от меток |

Единицы фотонные, как в калиброванном продукте ChemCam (photon/shot/mm²/sr/nm);
абсолютный масштаб не важен, потому что спектры нормируются.

Атомные данные — 50 неизменённых выгрузок NIST ASD (линии и уровни для 25 частиц:
H, He, Na, Mg, Ca, Fe, Si, Al, K, Ti, Mn, O, C), закреплённых SHA-256 в
[`nist_plasma_v3/sources.json`](../data/reference/nist_plasma_v3/sources.json);
компактная таблица — 11 267 переходов. Пересборка без сети: `make plasma-reference`.
Потенциалы ионизации берутся из строки «Limit» самих выгрузок (берётся наименьший
предел: дополнительные пределы относятся к возбуждённым состояниям иона).

Проверки в [`test_plasma_generator.py`](../ml/tests/test_plasma_generator.py):
закрытая форма уравнения Саха; совпадение интеграла линии в тонком пределе с
A·g_k·n·e^{−E_k/kT}/(4πU)·L с точностью 0,5% при двух температурах;
насыщение сильной линии; сохранение площади аппаратной функцией; воспроизводимость по
seed; согласованность меток и состава.

**Не моделируется** (сознательно и задокументировано): стадии III, самосогласованная
n_e и баланс зарядов, пространственные градиенты и самообращение линий, молекулярные
полосы (CN, C₂, CaO…), индивидуальные штарковские ширины (используется общая ширина
со случайным множителем для каждой линии).

## 2. Предобработка и признаки

- [`preprocessing/robust.py`](../ml/src/spectralab_ml/preprocessing/robust.py):
  фон методом асимметричных наименьших квадратов (ALS, λ = 10⁷, p = 0.01) и нормировка
  каждой полосы спектрометра на её суммарное излучение, как в обработке ChemCam.
  Полосы обрабатываются отдельно, разрыв между спектрометрами не соединяется.
- [`models/line_features.py`](../ml/src/spectralab_ml/models/line_features.py):
  признаки по окнам линий — пик в ±0.25 нм минус медиана боковых окон 0.6–1.5 нм,
  затем asinh(1000·x). Положения линий берутся из **синтетических** однокомпонентных
  LTE-шаблонов (T = 10⁴ K, n_e = 10¹⁷ см⁻³): 10 сильнейших линий на целевой элемент
  и по 5 на элементы матрицы. Реальные спектры при выборе признаков не используются.
  Модели: стандартизированная логистическая регрессия и HistGradientBoosting (one-vs-rest).
- [`models/calibration.py`](../ml/src/spectralab_ml/models/calibration.py):
  temperature scaling — одна температура на класс по NLL на половине validation,
  пороги — на другой половине. Монотонное преобразование: ROC-AUC не меняется.
- [`evaluation/plasma_validation.py`](../ml/src/spectralab_ml/evaluation/plasma_validation.py):
  операционные метки для приближённой оценки FPR (≥1 wt% оксида — положительная,
  (0; 0,1] wt% — отрицательная, остальное неизвестно; то же правило, что в
  [адаптации ChemCam](instrument_adaptation.md)) и ROC-AUC без порога.

## 3. Протокол replay

Наследуется из v1: 64 стандарта, усреднение повторов по физическому образцу,
сетка 350–800 нм с шагом 0,1, наблюдаемые окна 383–468 и 500–800 нм, пять seed
(7, 17, 29, 43, 71). Синтетика плазмы: 600 базовых составов × 2 «выстрела» на seed,
разбиение 60/20/20 по составу. Аппаратные ширины — диапазоны ChemCam VIO
0,15–0,3 нм и VNIR 0,4–0,8 нм из документации прибора.

| Вариант | Данные | Представление | Что изолирует |
| --- | --- | --- | --- |
| `neutral-linear/maxabs` | генератор v1 | max-abs в окнах | воспроизведение v1 тем же кодом |
| `neutral-linear/robust` | генератор v1 | ALS + нормировка полос | только предобработка |
| `plasma/maxabs` | LTE-плазма | max-abs в окнах | только генератор |
| `plasma/robust` | LTE-плазма | ALS + нормировка полос | генератор + предобработка; temperature scaling |
| `plasma/lines` | LTE-плазма | признаки по линиям | признаки по линиям |

Команды: `make plasma-replay` (нужны скачанные данные ChemCam, см. ML08) и
`make plasma-replay-dry` — проверка кода на синтетических «реальных» спектрах
без чтения кампании.

## 4. Результаты

Запуск `plasma-replay-20261022T200159-4679d3e8` (пересчёт после изменения
`select_thresholds`, см. ниже), статус completed, все 5 seed; сводка —
[`plasma_replay_v3_summary.json`](plasma_replay_v3_summary.json).
Значения — среднее ± SD по seed. Recall «все >0» — первичная метрика v1
(положительные метки с любым ненулевым содержанием). Операционные метки
(≥1 wt% против (0; 0,1] wt%): положительных Na 44 / Mg 45 / Ca 52 / Fe 53,
отрицательных **Na 14 / Mg 7 / Ca 2 / Fe 3** физических материала.

### Воспроизводимость v1 и порог по середине промежутка

Опубликованные числа v1 (recall NNLS 0,037, Logistic 0,455, RF 0,683) получены до
ML v4. После ML v4 `select_thresholds` ставил порог на минимальную оценку
положительного примера (верхний край промежутка между классами), и тот же скрипт
давал 0,0002 / 0,057 / 0,229. Теперь порог ставится посередине промежутка между
наименьшей принятой и наибольшей отвергнутой оценкой (schema 3). Перезапуск v1
`chemcam-external-20261022T200152-7bf6f309`: 0,009 / 0,267 / 0,263. Старая сетка из
51 точки ставила порог ещё ниже, поэтому опубликованные числа полностью не
возвращаются; это свойство прежней сетки, а не ошибка.

Полная таблица всех 18 комбинаций со стандартными отклонениями и FPR Ca/Fe — в
сводном JSON. SD по seed для строк выше не превышает 0,06 по recall «все >0».

Что из этого следует:

1. **Генератор — главный фактор.** При тех же моделях и предобработке замена
   нейтральной линейной синтетики на LTE-плазму поднимает recall с 0,01–0,27 до
   0,90–0,93. Предобработка без новой физики даёт меньше (Logistic 0,27 → 0,59)
   и ломает Fe (AUC 0,14).
2. **Ранжирование почти идеально, пороги не переносятся.** У признаков по линиям
   ROC-AUC по операционным меткам равна 1,00 для всех четырёх элементов. При этом
   FPR Na остаётся 0,58: порог, выбранный на синтетике, слишком низок для реального
   прибора. Для Mg точечная оценка лучше: recall 0,98 при FPR 0,01,
   но 7 отрицательных материалов недостаточно для гарантии FPR ≤5%.
3. **Высокий recall без FPR ничего не доказывает.** NNLS на плазме обнаруживает Ca и Fe
   во всех материалах (FPR 1,0), что равносильно ответу «всегда да». Для Ca и Fe есть
   только 2 и 3 отрицательных материала: их FPR и AUC — слабое свидетельство.
4. **Synthetic micro-F1 упал с 0,98–1,00 до 0,77–0,81 намеренно.** Новая синтетика
   содержит следовые содержания, матричные помехи и самопоглощение. Прежние 0,98–1,00
   измеряли лёгкую задачу, не переносящуюся на прибор.

### Калибровка (temperature scaling)

| Модель | ECE synthetic до → после | Brier операционный (реальный) до → после |
| --- | ---: | ---: |
| plasma/robust · Logistic | 0.109 → 0.081 | 0.212 → 0.161 |
| plasma/robust · RF | 0.076 → 0.034 | 0.089 → 0.063 |
| plasma/lines · Logistic | 0.052 → 0.030 | 0.038 → 0.041 |
| plasma/lines · Gradient boosting | 0.158 → 0.049 | 0.056 → 0.058 |

Temperature scaling стабильно уменьшает ECE на синтетике. На реальных операционных
метках Brier улучшился у двух моделей и почти не изменился у двух других. Решения
почти не меняются: преобразование монотонное, а пороги выбираются после него.

## 5. Ограничения и следующий шаг

- Это replay раскрытой кампании. Диапазоны генератора взяты из литературы и
  документации прибора до запуска, но автор видел результаты v1.
- Отрицательная поддержка мала; для Ca и Fe FPR фактически не оценён.
- Модели не сохраняются как артефакты API; новые представления пока используются
  только в исследовательском скрипте.

Модели те же, порог Na/Mg/Ca/Fe подбирается на 127 лабораторных спектрах calib_2015

[`plasma_real_thresholds_v4_summary.json`](plasma_real_thresholds_v4_summary.json).
Для `plasma/lines` с логистической регрессией на 71 образце calib_2021, recall / FPR,
порог с синтетики → порог с calib_2015: Na 0,76 / 0,33 → 0,70 / 0,00; Mg 0,88 / 0,12 →
0,91 / 0,15; Ca 0,83 / 0,24 → 0,73 / 0,00; Fe 0,75 / 0,32 → 0,64 / 0,02. На preflight
FPR Na 0,58 → 0,03, Ca 1,00 → 0,00. Пороги с calib_2015 не зависят от
`select_thresholds`, поэтому эти числа совпадают с прогоном до его изменения. calib_2021 раскрывался ранее в адаптации, поэтому
это тоже replay. Подробности — в [CHANGES.md](../CHANGES.md), раздел 11.

## 7. Интервалы FPR и recall · поправка 2026-10-23

`operational_report` сначала усредняет бинарные решения повторных спектров
внутри каждого физического материала, затем одинаково взвешивает материалы.
Доли внутри материала могут быть дробными, поэтому биномиальный интервал
по числу спектров здесь неприменим. Прежний percentile bootstrap давал
вырожденные `[0, 0]` при отсутствии наблюдаемых ошибок.

Теперь `ci95` — консервативный двусторонний интервал Hoeffding для среднего
независимых величин в [0, 1]: `mean ± sqrt(log(40) / (2*n))`, обрезанный до [0, 1].
`n` — число физических материалов с известной соответствующей меткой. Например,
0 ошибок на 2 материалах дают [0; 0,9603], на 100 — [0; 0,1358]. Повторение
одного спектра не повышает support и не сужает интервал. При отсутствии поддержки
значение и интервал — `null`. Метод, уровень, единица и предпосылки записываются
в `rate_interval`; старые bootstrap-параметры принимаются для совместимости,
но не управляют новым интервалом. [Первоисточник: Hoeffding, 1963, Theorem 2](https://doi.org/10.1080/01621459.1963.10500830).

Это точечные интервалы для отдельного элемента и отдельной метрики; они не
покрывают одновременное сравнение всех элементов, неопределённость химического
анализа или зависимость материалов. Независимость `sample_ids` — предпосылка,
которую необходимо подтвердить происхождением данных. Низкое содержание
не становится сертифицированным blank.

Исторические сводки 22 октября сохранены: mean/SD по пяти seed описывают
вариабельность запусков, а не доверительный интервал FPR по материалам. Реальные
спектры для этой поправки не пересчитывались; проверка формулы выполнена на
синтетических unit-fixtures. Новый независимый final остаётся открытым.
