# Roadmap

Ниже — рекомендации, не заявленные реализованными.

1. **Исследовательская оценка.** Запускать конфигурации на нескольких фиксированных
   seed, хранить все run-ID и показывать среднее/разброс. Синтетический один seed не
   заменяет внешнюю валидацию.
2. **Физика.** Добавить Voigt и отдельные механизмы уширения, физически мотивированный
   фон, Poisson/read noise, насыщение/response детектора и документированную
   air↔vacuum-конверсию. Для каждого расширения нужны тест нормировки и параметры
   происхождения.
3. **Справочник.** Поддержать несколько `ion_stage` без смешения их меток, шаблонов и
   diagnostics. Пополнить трассируемые сохранённые выгрузки NIST.
4. **Модели.** Добавить 1D CNN как необязательную точку расширения, без PyTorch в
   минимальном runtime; сравнивать на фиксированном split с сохранёнными seed/checkpoint.
5. **Реальные данные.** Собрать трассируемые измерения с прибором, условиями, эталоном,
   единицами и split по физическому образцу/сессии. Только затем проверять transfer
   synthetic→real.
6. **Неизвестные элементы.** Спроектировать отдельный open-set/abstention протокол.
   «Поддерживаемые элементы не обнаружены» не доказывает отсутствие вещества или
   неизвестный элемент.

Количественный анализ не входит в этот roadmap: `component_weights` не получают смысл
концентраций.
